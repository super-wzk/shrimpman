# 装备特效定义中的动画字段

本文记录 ZZ HD 客户端 DAT 161 和 166 的离线字段解析。两张表分别使用 128、180
字节记录，不能套用相同的记录布局。每条记录的全部字节都参与解析／序列化，浮点数
保存为原始 u32 位模式；未知字段和标志的未知取值不清零、不归一化。

字段含义以 `mhfo-hd.dll` 的原生读取代码为依据。只读资源测试使用
`MHF_RESOURCE_GAME_ROOT` 下的 `dat/mhfdat.bin` 验证定义记录，记录数量取自 DAT
计数块，不固定为某个资源文件的数量。本文偏移均相对定义记录起点。

## 模型绑定与资源身份

DAT 165 的 `model_id` 由 `10BBA300` 与装备模型 ID 比较；不能从 DAT 161／166 的局部节点或材质槽推断归属。
已确认的文件构造入口如下，工作台仅反解这些格式：

| 原生入口 | 资源格式与范围 |
| --- | --- |
| `108E0550`、调用者 `108E1780` | 普通武器 `weapon/w%c%03d.bin`，字母为 `model_id / 1000 + 'e'`、数字为余数；例如 `wi521.bin` 对应 4521。可带 `-so` 后缀。 |
| `108E06F0`、表 `11887984` / `1199F970` | 普通部件使用 `m_` / `f_` 加 `hair/head/body/arm/wst/leg` 和模型编号；编号小于 1000 时补三位，否则至少四位。部位和性别共同确定匹配。 |
| `108E23D0 → 108E20A0 → 108FCA00 → 10AE26F0 / 10AE2430` | 特殊分支（variant 2）分别使用 `npc/n47w%04u.bin`、`n47h%04u.bin`、`n47b%04u.bin` 表示武器、头部和身体。其余部位没有独立文件映射证据。 |

武器分支只区分 variant 是否为 2，普通分支的 0／1 不产生不同性别的武器文件。
未确认格式不自动匹配；多个已加载模型具有同一资源身份时保持未绑定，允许手动选择。
手动改绑或解绑不会被后续自动匹配覆盖，只有明确恢复自动模式才重新使用上述规则。
这些规则确定资源归属，不模拟装备类别、特效条件或玩家状态。

## 模型特效定义：DAT 166

生效条件及动画、状态字段的布局如下：

| 偏移 | 类型／长度 | 含义 |
| --- | --- | --- |
| 0x0c | u8 | 生效条件 ID，`10BBCBD0` 的状态分支选择值 |
| 0x12 | 2 字节 | 未确认，`unknown_12` 仅覆盖这两字节 |
| 0x14..0x16 | 3 × u8 | X/Y/Z 旋转状态联动标志 |
| 0x17 | u8 | 未确认 |
| 0x18、0x24、0x30 | 3 × 12 字节 | X/Y/Z 旋转动画 |
| 0x3c、0x50、0x64 | 3 × 20 字节 | X/Y/Z 缩放动画 |
| 0x78 | u8 | 渲染标志，交给 `114067E0` |
| 0x79 | 3 字节 | 未确认，保留原值 |
| 0x7c | 12 字节 | RGB 动画 |
| 0x88 | 9 字节 | 透明度动画 |
| 0x91 | u8 | 原生渲染状态键 0x60 的值，枚举含义未确认 |
| 0x92 | 2 字节 | 未确认 |
| 0x94 | 13 字节 | UV 动画 |
| 0xa1 | 7 字节 | 未确认，保留原值 |
| 0xa8 | u8 | 武器显隐选择值 |
| 0xa9、0xaa | 2 × u8 | 显隐条件模式、掩码，交给 `10BBA160` |
| 0xab | u8 | 未确认，保留原值 |
| 0xac | u8 | 条件切换标志，初始化到运行时 +141 并由 `10BBCBD0` 消费 |
| 0xad | u8 | 终态初始化及额外变换标志 |
| 0xae | 6 字节 | 未确认 |

`10BBA7A0` 初始化动画通道，`10BBE150` 和 `10BBF340` 消费这些参数。

旋转通道包含 i16 起始角度、i16 结束角度、i16 重复次数、u16 周期步数和原始 f32
状态速度倍率。`10BBB1B0` 按武器状态调整速度，`10BBC1F0` 计算通道值。
绘制路径乘以已核对的 pi 和 1/180 常量，再调用 `1000D130` → `10004F80` 的
X/Y/Z 旋转，因此角度字段可以标示为度数。

缩放通道在 +0/+4 保存 f32 起止值，+8 为四字节参数，+12 是 i16 重复次数，+14
是 u16 周期，+16/+17 是两个独立字节，+18 是两字节未知数据。+17 在 `10BBBE40`
中选择往返或单向变化。仅 Z 通道确认 +16 选择有状态插值 `10BBBF80`，+8 是
`10BBB1B0` 使用的速度倍率；X/Y 的对应字段仍标为未确认。三个缩放值送入
`1000CF90` → `D3DXMatrixScaling`，与记录开头的位移增量分别处理。

UV 的 0x94/0x96 为 i16 U/V 周期，0x98 为 u16 循环步数，0x9a 为 i16 重复次数，
0x9c 为 f32 状态步进参数，0xa0 为模式原值。`10BBC330`、`10BBC500` 使用
`(counter % period) / period` 构建纹理平移矩阵。调用点 `10BBE8AB..10BBE8E5`
的汇编确认 CX 对应 +0x94，栈参数分别传 +0x96、+0x98；不能仅靠反编译器省略了
寄存器参数的调用摘要推断字段。模式非零时会追加运行时步进，模式 4 另调用
`10BBDE80` 的位置／朝向相关映射；其完整枚举未赋予猜测名称。

`10BBAAC0` 在 +0xad 非零时设置终态初始化，`10BBF340` 也用同一字节选择额外
变换路径。该标志不能简单理解为一个独立的“循环开关”。

## 附着特效定义：DAT 161

生效条件及动画字段使用独立布局：

| 偏移 | 类型／长度 | 含义 |
| --- | --- | --- |
| 0x0c | u8 | 生效条件 ID，`10BB2AB0` 的状态分支选择值 |
| 0x0f | u8 | 未确认，`unknown_0f` 仅覆盖这一字节 |
| 0x10 | u16 | 默认资源 ID，序列播放未启用时传给 `10BBA050` |
| 0x12 | u16 | 启动延迟 |
| 0x14 | 8 字节 | 资源序列：i16 起止 ID、重复次数、切换间隔 |
| 0x1c、0x24、0x2c | 3 × 8 字节 | X/Y/Z 旋转：i16 起止角度、重复次数、u16 周期 |
| 0x34 | 14 字节 | 统一缩放：f32 起止值、u16 往返标志、i16 重复次数、u16 周期 |
| 0x42 | 4 字节 | 未确认 |
| 0x46 | u8 | 渲染标志，交给 `10BB28D0` |
| 0x47 | 3 × u8 | 朝向矩阵选择标志，尚不命名为独立 XYZ 轴开关 |
| 0x4a | 12 字节 | RGB 动画 |
| 0x56 | 9 字节 | 透明度动画 |
| 0x5f | u8 | 原生渲染状态键 0x60 的值 |
| 0x60 | 2 字节 | 未确认 |
| 0x62 | 8 字节 | UV：i16 U/V 周期、u16 循环步数、i16 重复次数 |
| 0x6a | 2 字节 | 未确认 |
| 0x6c | f32 位模式 | 沿归一化视线方向附加的偏移 |
| 0x70 | u8 | 拖尾模式：0 无拖尾，1 调用 `10BB4E60`，2 调用 `10BB5A90` |
| 0x71 | 3 × u8 | 拖尾 RGB，模式 2 中参与颜色计算 |
| 0x74 | u8 | 武器显隐选择值 |
| 0x75、0x76 | 2 × u8 | 显隐模式和条件掩码，交给 `10BBA160` |
| 0x77 | 2 字节 | 未确认，保留原值 |
| 0x79 | u8 | 终态初始化标志，经 `10BB0C70` 触发 `10BB08E0` |
| 0x7a | 6 字节 | 未确认，保留原值 |

`10BB0830` 初始化计数器，`10BB2AB0` 执行序列、旋转、缩放、颜色和 UV 更新。
`10BB3D72` 的汇编读取 +0x10 作为未启用序列时的资源 ID；启用序列时使用 +0x14
到 +0x16 的变化 ID。`10BB4664` 将选择结果传给 `10BBA050` 进行资源注册表查找。
这里的 ID 不解释为模型特效定义 ID 或纹理编号。

缩放系数乘到附着矩阵的全部三轴，因此是统一缩放；没有复用 DAT 166 的三条
20 字节缩放通道。拖尾函数维护多帧变换矩阵并生成后续绘制，颜色字段的读取由
`10BB5A90` 的 +113/+114/+115 访问确认。视线偏移由 `D3DXVec3Unproject` 的
结果与附着点作差、归一化后乘 +108 的浮点值得到。

## 共同的数据语义与验证

RGB 都是两组三字节颜色、u16 往返标志、i16 重复次数和 u16 周期。透明度都是
两个 u16 端点、i16 重复次数、u16 周期和一个 u8 往返标志。二者结构相同但在
两类记录中的偏移不同，求值代码也分别处理。透明度存储保留完整 u16，不因渲染时
转换成 u8 就在解析阶段截断。

重复次数按有符号数显示：原生动画循环只递减正值，负值不递减，零不进入对应动画
分支；序列播放还明确把 0xffff 当作循环值。状态条件和终态初始化仍可能改变播放。
时间字段保留原生更新步数，不假定 FPS 或毫秒。

测试包含独立字段偏移／类型断言、负值、未知字节、NaN 与负零、局部修改的写入范围、
工作台对全部 128/180 字节不重叠的字段覆盖，以及全部原始定义的逐字节往返验证。
工作台可单独选择定义，以临时姿态及材质副本预览节点位移、旋转／缩放、RGB／透明度、模式 0 UV 滚动和渲染标志；
无有效动画时显示起始颜色。任意定义可手动触发、重播和停止，原生条件不限制触发，
UV 按 `10BBC330` 的有符号周期和独立循环计数器求值，通过参数 25 上传矩阵；绘制时启用
第一渲染状态字的 `0x4000` 位，含使用模型内缓存状态字的路径，绘制后恢复。
触发或重播会立即停止其他冲突定义，停止后不自动恢复旧定义。161 仅支持模式 0 的附着点定位。旋转／缩放使用标准周期插值，完整状态速度反馈、其他 UV 模式、拖尾和
资源注册表仍未接入，也未通过运行时改参验证所有分支。

工作台各轨道从局部第 0 步开始并保留真实延迟。特效长度为延迟加最长有效通道：
有限重复计入全长，无限重复取该通道一轮，静态定义在延迟后至少保留 1 步；显示长度不代表多通道的联合周期。
每条轨道按自身范围占满宽度并显示当前／总步数，共用播放速度；拖动和逐步只调整对应轨道。
定位、停止、移除及加载／卸载 MOT 不改变其他轨道的进度；触发、重播只停止冲突轨道，停止项须重新触发。
各通道继续遵循 DAT 的有限或无限重复参数，不随模型动画重置。详见工作台 README。
