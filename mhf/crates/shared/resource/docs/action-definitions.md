# DAT[389] 武器招式

以下布局来自 HD `mhfo-hd.dll` 的静态读取路径，地址以该 DLL 的 `0x10000000`
映像基址表示。它描述武器招式的三张数据表，不覆盖通用动作与怪物原生状态分支。
解析和字节往返验证不代表实际游戏中的输入、派生或动画已经验证。

## 目录与招式头

DAT 根字段 `389 * 4 = 0x614` 指向 14 个武器目录项，每项八字节：
`count: u32`、`records_pointer: u32`。目录内每个招式头为 24 字节：

| 偏移 | 类型 | 字段 |
| --- | --- | --- |
| +0 | u32 | step_count |
| +4 | u32 | steps_pointer |
| +8 | u32 | transition_count |
| +12 | u32 | transitions_pointer |
| +16 | u32 | event_count |
| +20 | u32 | events_pointer |

`10AF5140` 的 DAT[389] 重定位循环逐武器、逐招式改写 `+4/+12/+20`，
三个非零字段都加上 DAT 映像基址。`10A67790` 消费步骤，`10A68110` 消费派生条件，
`10A68510` 消费事件。离线值是相对 DAT 映像的偏移，运行时值是重定位后的地址；
共享解析器通过显式 `base` 还原输入字节范围，不保存宿主指针。

## 步骤与事件

步骤为六个原始 `u16`，共 12 字节：`kind/value/arg_a/arg_b/frame/count`。
`10A67790` 的 `10A67836` 分支按 kind 控制推进：3 等待步骤计数达到 count，
4 同时等待计数和 `108FF7A0` 的帧条件，5 保持当前步骤。
其他 kind 不使用这三个等待分支。

新步骤在 `10A67899` 起读取：0、1 分别调用 `10A81AF0/10A81C20`，
2 将 value 交给招式切换回调，其他值交给武器步骤回调，或默认的 `10A92CD0`。
因此未知 kind 保留原值；默认动画路径不能证明所有武器回调都只做动画播放。

事件前八字节与下面的 `ActionCondition` 同布局，后四字节为
`operation: u16` 和 `argument: u16`。`10A68510` 按原始事件顺序推进游标，
将操作和参数交给武器回调；操作编号的含义依赖武器类别。

## 派生条件

`10A68110` 在 `10A681CB` 检查招式 `+8` 的数量，`10A681D1` 从 `+12`
取得表指针，`10A682F7/10A68411` 以 40 字节步长前进。每条记录如下：

| 偏移 | 类型 | 字段 | 已确认的用途 |
| --- | --- | --- | --- |
| +0 | u16 | priority | 候选优先级值；与已选记录的 priority 经 u16 回绕加 1 后的阈值比较 |
| +2 | u16 | input | 交给武器输入回调；返回值参与选择与触发 |
| +4 | u16 | selection | 选择编号；`10A683D4` 读取低字节构造掩码，`10A68440` 读取整 word 匹配选择回调结果 |
| +6 | ActionCondition | input_start | 输入窗口起点 |
| +14 | ActionCondition | input_end | 输入窗口终点 |
| +22 | u16 | argument | 最终交给武器切换回调的参数 |
| +24 | ActionCondition | transition_start | 切换窗口起点 |
| +32 | ActionCondition | transition_end | 切换窗口终点 |

四个条件的达成状态分别存入输入状态块 `+28/+32/+36/+40` 的位掩码。
起点已达成、终点尚未达成时窗口生效；`10A68477/10A6847E` 根据输入窗口更新选中记录，
`10A684CE/10A684D6` 在输入回调返回 2 且切换窗口生效时调用切换回调。
输入编号、选择编号和切换参数保留原始数值，不跨武器猜测按键或目标动作。
原生使用 32 位窗口掩码是执行路径的事实，不据此补造文件中未验证的记录数量约束。
优先级过滤使用无符号 word 比较；最终候选还取决于武器选择回调和遍历顺序，
不将它简化成自动选择数值最大的记录。

## 八字节条件

`ActionCondition` 保留如下字段；phase 的有符号比较由 `10A680BE/10A680C0` 确认。

| 偏移 | 类型 | 字段 |
| --- | --- | --- |
| +0 | u16 | step |
| +2 | u8 | timing |
| +3 | i8 | phase |
| +4 | u16 | frame |
| +6 | u16 | count |

`10A68090` 将文件 step + 1 与 actor 的步骤游标 `+3990` 比较：
游标已越过该步骤时条件达成，尚未到达时不达成。恰在该步骤时，timing 为 1
直接达成，2 不达成；其他值要求 actor `+820` 非零。
phase 大于零时比较 actor `+520 <= phase`；否则比较步骤计数 `+3992`：
计数大于 count，或计数等于 count 且 `108FF7A0(frame)` 达成时通过。
未知 timing 和负 phase 均保留，不能把它们当作解析错误。

工作台保留物理序号和可编辑字段范围，例如
`mhfdat.bin#389/4/0/transitions/0/input_start/phase`；
`transition_span` 返回完整 40 字节记录范围，`to_bytes` 保持各字段的原始位模式。
