# SDT 攻击、判定与分类参数

武器攻击的基础动作值可从 `dat/mhfsdt.bin` 的攻击参数表读取。客户端先解码资源，
再把表中的记录复制到攻击实例；部分初始化路径另有 DLL 内置备用表。
`mhfdat.bin` 的武器面板属性和 G50／天廊等级属性表不是这里的基础动作值表。

`sdt` 模块解析目录、攻击参数、辅助参数、八槽判定组和类别专用参数。
工作台支持逐级展开、定长字段编辑及 ECD／JKR 回包。字段含义来自下述原生消费者，
不把攻击参数记录编号命名为具体招式；招式名、武器类别、动画 ID 与参数编号的
完整映射尚未建立。目录类别也不等同于武器种类。

## 从文件到攻击实例

1. `10AFCD10` 从全局 `11A460C4` 取得文件名指针；其目标 `1199E138` 为
   `mhfsdt.bin`。加载器解码、解压后把基址保存到 `1E77DCD4`。
2. 类别目录每条 `0x1c` 字节，`+0x02 == 0xffff` 终止。
   加载器把目录 `+0x08/+0x0c/+0x10/+0x14` 的非零偏移加上解压后基址，
   并处理 `+0x10` 引用的下级指针。随后会排序目录，因此不能以运行时目录顺序
   代替原文件目录顺序。
3. `10AFCFD0` 按目录 `+0x02` 的类别键查找；`10AFD040` 则查找
   `(6 << 16) | subtype`，同时比较 `+0x00` 的子类别键。
4. 类别 0 的初始化 `111D9370` 在 `111D93B1` 将 EAX 清零，调用 `11322200`。
   找到 SDT 条目后，将目录 `+0x08` 的攻击表地址替换到 `11A00704`；
   未找到时保留 DLL 内的 `116C2300`。
5. `111D9370` 从攻击实例 `+0x06` 读取 u16 记录编号，经 ECX 传入
   `111D61C0 → 10A93600`。
6. `10A93654..10A93669` 执行以下复制：

   ```text
   table = *(*(effect + 0xa8))
   memcpy(effect + 0x68, table + index * 0x28, 0x28)
   ```

所以记录 `+0x04` 对应攻击实例 `+0x6c`，类型为小端 u16。
这是基础威力／动作值字段；记录其余字节不能都解释为动作值。

`111E2360` 的另一攻击初始化路径经 `11322280 → 10AFD040` 选择类别 6
及子类别，再使用同一个 `10A93600` 复制器。不能假定所有武器攻击都用类别 0。

## 伤害消费者与后续修正

`108BC1B0` 为命中后的大型处理函数。`108BF45F` 以 `movzx` 读取攻击实例
`+0x6c`，转换为浮点；`108BF585..108BF59C` 将其与前面计算的倍率及攻击力项
相乘，再交给 `108B7D60`。这些路径足以把复制记录中的 `+0x04` 与伤害威力联系起来。

表中数值不是最终伤害。已确认还有下列改写：

- `111D61C0` 在复制后调用 `10899670`，后者可缩放实例 `+0x6c`。
- `111D6D20` 按技能条件与攻击类别／编号取额外值，再加到实例 `+0x6c`。
- `111D8230` 等路径会再次缩放该字段。

因此离线导出的基础值、运行时修正后的动作值和最终伤害应分别表示。

## 当前样本的可复现位置

解压后样本有 104 条目录记录，终止记录位于 `0x0b60`。
目录第一条为子类别 0、类别 0，`+0x04` 存储 271，`+0x08` 存储
`20 04 0b 00`，即攻击参数表偏移 `0x0b0420`。
按样本中的目录数量字段检查，104 个攻击表的 `table_offset + count * 40`
均未超过解压后数据长度。

类别 0 的基础动作值位置为：

```text
table_offset = read_u32_le(decoded_sdt, directory_offset + 0x08)
value_offset = table_offset + attack_parameter_index * 0x28 + 0x04
base_motion_value = read_u16_le(decoded_sdt, value_offset)
```

| 参数编号 | 解压后数值偏移 | SDT 基础值 | IDA 样本 DLL 备用值 |
| ---: | --- | ---: | ---: |
| 1 | `0x0b044c` | 58 | 56 |
| 2 | `0x0b0474` | 46 | 44 |
| 3 | `0x0b049c` | 60 | 58 |
| 6 | `0x0b0514` | 30 | 15 |
| 7 | `0x0b053c` | 52 | 52 |
| 8 | `0x0b0564` | 52 | 45 |
| 10 | `0x0b05b4` | 40 | 24 |
| 11 | `0x0b05dc` | 100 | 82 |

备用表 VA 为 `0x116c2300`、RVA 为 `0x016c2300`，在本次 IDA 输入 DLL 中的
磁盘偏移为 `0x016c0b00`。这些位置只适用于上述 DLL 样本；不能用于游戏目录
中另一个哈希的 DLL。

表中的 `0x0b044c` 等位置是 **ECD 解码并 JKR 解压之后** 的 SDT 偏移，
不在 82,360 字节原始文件的同名偏移处。更换资源版本后应重新读取目录，
不能固定使用 `0x0b0420`。这些差异也说明仅查看 DLL 备用表不足以确定实际使用值。

## 完整目录与识别边界

所有偏移相对解压后的 SDT 起点，零引用和未使用值保持原样。

| 目录内偏移 | 类型 | 数据 |
| --- | --- | --- |
| `00` | u16 | 子类别键；类别 6 的查找同时比较此键 |
| `02` | u16 | 攻击／效果类别键；`ffff` 终止目录 |
| `04` | u16 | 攻击数，以及辅助参数的原生索引上限 |
| `06` | u16 | 判定组数；不能与 `04` 合并读成 u32 |
| `08` | u32 | 40 字节攻击参数表偏移 |
| `0c` | u32 | 16 字节辅助参数表偏移；允许缺省 |
| `10` | u32 | 判定组目录偏移，每组八个 u32 列表引用 |
| `14` | u32 | 32 字节类别专用参数表偏移 |
| `18` | u32 | 类别专用参数记录数 |

`10AFD0F0`、`11322200` 和 `11322280` 按目录 `04` 检查辅助参数编号上限。
它没有独立的物理数量字段。本次样本中类别 146 的辅助表起点 `b9d30` 距下一个
引用 `b9d40` 仅 16 字节，但索引上限为 68；类别 151 也有类似短表。
解析器按原生可索引窗口展示，允许与别的区域重叠，不由相邻引用推测真正表长。
工作台明确标示这个限制，不把窗口数量报告为物理独立辅助记录数。

`Sdt::parse` 在明确文件上下文中读取目录，具体表与列表由访问器检查；一个坏引用
不会使其他目录项消失。`Sdt::probe` 用于无文件名识别，先做首条目录的低成本
边界检查，再完整检查引用、数量和列表终止符。纯零数据、无引用目录和重复类别键
不能用作 SDT 识别证据。没有可靠结构证据的匿名数据仍作为原始数据。

没有独立魔数、版本字段或校验头可用于确定 SDT 的内部版本，因此这些结构支持
所记录的原生消费布局，并不宣称所有历史版本相同。

`0x2/0x4/0x1/0x1000000` 另有异常路径；不将整个 u32 简化成单一元素枚举。

## 八槽判定组与 40 字节判定记录

`10AFCE70..10AFCEA5` 按目录 `06` 遍历组，每组重定位八个列表引用。
每个列表按 40 字节步进，以首 u16 为 `ffff` 结束。零指针没有被原生定义为
“空槽”；实际空列表仍是非零引用，指向一个终止字段。

列表指针保存到攻击实例 `+0xa0`，由 `108C5510/108C5910/108C69C0` 等消费。
大量槽和组共享列表或列表尾段，解析器保留原槽号和偏移。槽的选择由调用者决定：
`11323160 → 10899270` 使用武器长度数据，类别 100 的 `11204580` 则使用
持有者状态 `+2856 % 3`，不能把八槽命名成八种武器。

通常几何的字段为：`00` u16 节点／模式，`02` u16 形状（0 球体、1 胶囊），
`08` u32 判定标志，`0c` f32 半径，`10/14/18` 三个 f32 中心或起点，
`1c/20/24` 三个 f32 胶囊终点。`04..07` 未确认；球体不用的尾坐标保留原始字节。

| 节点／模式值 | 已确认行为 |
| --- | --- |
| `0..117` | `10A93DD0/10A93D70` 使用 448 字节节点矩阵变换局部坐标，再加平移；标志 bit 3 可转向专用武器矩阵 |
| `119` | `10A94360` 使用实例当前／前次位置作胶囊端点，再叠加记录 `10` 的缩放偏移 |
| `120` | `10A94650` 将局部坐标缩放、旋转并平移 |
| `121` | `10A94410` 旋转、平移局部坐标；半径仍缩放，局部坐标本身不缩放 |
| `122/123/126` | `10A94360` 使用不同的实例历史位置端点；不用文件中的端点坐标 |
| `124/127` | `10A94290` 使用不同实例位置作平移基准，不旋转 |
| `125` | 条件跳过指令；`02` u16 状态掩码，`04` i16 跳过数量，`108AF5A0` 按 `40*(1+count)` 前进 |
| `118` 或其他未确认值 | 只呈现模式号，其余字节保持原值 |

解析器列出物理顺序中的指令，不执行条件跳过，也不把负跳转转成宿主指针。
目标身体碰撞表也使用相同步长；其额外过滤位不能直接推广给所有 SDT 攻击列表。

## 16 字节辅助参数的分类解释

`11322200/11322280` 将选定目录保存到实例 `+0x174`，将
`auxiliary + 16*u8(effect+6)` 保存到 `+0x178`。复制到工作区后的已确认读取包括：

| 类别／编号 | 字段与含义 | 原生消费者 |
| --- | --- | --- |
| 100 | `00` i32 攻击分支类型，`04` i32 按部位命中累积量，`08` i32 可缩放参数，`0c` u32 攻击行为标志 | `111D7D50/108BBCE0/11204814/1120526F` |
| 106／107 | `00` i32 眩晕累积增量，加到攻击实例 `+137` 并限制到 255 | `10316120` |
| 160，16..18 | `08/0c` i32 本地玩家水平显示距离上下阈值 | `10200170/10200360` |
| 160，45 | `00/04` i32 竖直／前向初速度，`08` i32 竖直加速度，`0c` i32 两速度共用随机扰动范围 | `101FF360` 初始化；`10201D80` 移动、积分加速度并检查落地 |
| 160，47 | `00` i32 命中标识刷新间隔 | `1020280A` 以全局计数取模 |
| 160，48..50 | `08` i32 显示距离阈值，乘父实例缩放 | `10202830/10202990` |

类别 160、编号 45 的样本值 `(10, 50, -3, 50)` 因此属于抛射运动参数。
类别 100 的部位累积量进入目标 `+3314 + 2*part_index` 并检查上限；尚不将它
强行命名为某种游戏内槽名。它的行为标志 bit 0／1 分别设置实例特性，bit 2／3
依据目标 `+0x10` 的两种类别另设特性；没有给这些位猜“穿透”等名称。

## 32 字节类别专用参数

`109A2C60` 接收 EAX 记录号和 ECX 目录，检查目录 `18` 后从 `14 + index*32`
取记录，缺省使用 `11880F08`。相似的 `109A2C30` 实际读的是 DAT 表，不能混用。
`11324080/11324140` 分别取前／后四槽，调用者决定类型与用途。
工作台按类别、记录号和当前范围表选择布局，未确认记录保留全部原始字节。

类别 100 的武器修正包括：

- `1..25 / 27..51 / 53..77`：`11205050` 的三个辅助类型修正库，变体 2 时
  逐项修改攻击 23 字段及辅助 `04/08`。本行 `04` 为 f32 修正值，`14` 为 i32
  操作。`11204CE0` 明确操作 1 替换、2 相加、3 相乘，其余不修改。
- `103..105/147..149` 修正指定攻击号的基础威力，`107..109/150..152` 修正眩晕；
  `111..114/120..123` 还有其他攻击组。`11205520` 读取 `116B16C8/116B1728/116B1788`
  的静态映射，字段名使用实际攻击编号，不伪造招式名。每槽 `4*i` 为 f32 数值，
  `16+4*i` 为 i32 操作；未使用的槽仍保留。
- `85..87` 按连段层数追加基础威力、眩晕、辅助两项累积量；`95` 控制部位累积
  触发后的计数；`98` 的三个低 u16 在特定技能条件下覆盖攻击 4、5、96／97 的威力。
- `125` 的两个 i32 给出斩味表起止记录；该范围内前四 f32 经整数转换比对攻击号，
  后四 i32 交给 `10A98950`。`129/136` 分别选择部位累积和武器计算数值的
  连段百分数表范围。布局每次读取当前范围，编辑范围后不会沿用旧样本行号；
  负数、逆序、越界不生成范围解释。固定原生记录语义优先于冲突范围。

## 工作台与验证

打开 `mhfsdt.bin` 后展开 SDT 目录项，可分别进入“攻击参数”“辅助参数”
“分组判定”“附加参数”。判定组继续按槽、列表和记录展开；类别专用字段直接
来自共享资源层，避免 UI 再解释一套偏移。每条记录未定义部分、终止行未使用字节、
对齐数据及未归属块都可查看原始字节。没有生成模拟游戏的伤害或碰撞预览。

文件层原始字节和解码层偏移始终分开。定长编辑沿已确认的 buffer 范围写回，
共享引用对应同一字节位置；重建已展开节点后，球体改为胶囊会显示相应端点字段。
保存经现有编码器重建 ECD／JKR，未编辑源文件不会被读取或浏览动作改写。

真实样本遍历结果：104 类别，4,116 条攻击记录，3,421 条辅助可索引窗口记录，
2,264 个八槽组，1,889 个不同起点的判定列表，合计 7,355 条判定记录，本样本
记录偏移也互不重复，以及 2,732 条类别专用参数。槽引用有大量别名，其他输入还可
共享列表尾段；批量验证按同一步长复用终止位置，避免重复扫描。
另有 101,938 字节未归属到这些已读取范围，包含终止行尾部和对齐区；
其中仅 410 字节非零，仍完整保留，不能把它们直接假定为全部填充。

合成测试覆盖坏引用局部失败、EOF 终止、别名、动态参数范围、未知值、NaN／负零、
嵌套非零 buffer 起点、类型变化后的视图重建和编码层定长编辑回包。真实资源测试
按声明数量遍历各表和不同列表，并核对字段范围及所有剩余字节的可达性。
样本数量不是格式常量，也不证明每个未知字段已还原。
