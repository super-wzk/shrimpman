# 怪物 AI opcode 索引

`case 块`、`handler`、`操作`、`域` 取自本目录的逐区间记录，`摘要` 与
[`opcode-matrix.md`](opcode-matrix.md) 的语义矩阵一致；`0x00..0xff` 每个字节
恰好一行。`case 块` 是跳转表里的解释器 case 地址，`handler` 是它调用的原生
例程；`操作`、`域` 两列保留记录里的原始枚举值，含义见
[`opcode-catalog.md`](opcode-catalog.md)。
