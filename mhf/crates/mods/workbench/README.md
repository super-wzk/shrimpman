# 资源工作台

`mhf.workbench` 是与 `mhf.debug` 并列的启动 Mod，依赖 `mhf.base`，使用同一个
`mhf-launcher`，通过 `mhf.config` 保存视图设置。启动后保留空预览，不加载猎人、任务或地图。

```toml
[mods."mhf.workbench"]
enabled = true

[mods."mhf.debug"]
enabled = false

# 可选配置，路径相对游戏目录。
[mods."mhf.workbench".settings]
data_root = "dat"
export_root = "workbench-exports"

[mods."mhf.workbench".settings.view]
# 模型预览区背景 RGB，各分量为 0–255，默认深灰色。
background_color = [16, 19, 22]
```

工作台和 Debug 都提供普通启动接口，不能同时启用。Login 是 fallback，可保持默认选择。
默认构建包含 `workbench` feature，但不会自动启用这个 Mod。
Nix 的 `development.mhf.workbench.enable = false;` 会从启动器和管理器的构建中移除它。

工作台默认使用 `egui-hunter::Density::Compact`，在保留字号的同时缩小控件高度、间距与留白。
“视图”菜单可切回标准密度；该设置只作用于工作台，不改变同一 UI 上下文中的其他界面。
“视图 → 模型预览背景”直接显示二维调色板、色相光谱和 RGB 输入，可实时调亮模型背后的底色，
并恢复默认深灰色；空预览、专注预览和隐藏界面时同样生效，界面面板颜色保持原主题。
选色拖动结束后自动保存到本次启动使用的配置文件（包括 `--config` / `MHF_CONFIG` 指定的文件），
下次启动恢复。“视图”中的紧凑模式、资源目录、编码层、检查器、日志、专注预览及骨架显隐也自动保存。
保存失败会显示错误，可在“视图”菜单重试；切换全屏仍由游戏原生设置处理。
模型预览工具栏的“网格”和“坐标”默认开启，也可在“视图”菜单切换，开关自动保存。
地面网格位于世界坐标的 XZ 平面（Y=0），随缩放按 1/2/5 系列调整间距，每五格显示较醒目的主线；
网格始终与世界坐标对齐，线色适配当前背景，并由模型深度遮挡。
坐标显示包含世界原点的红 X、绿 Y、蓝 Z 轴、右上角随相机旋转的方向指示，以及左下角的
焦点世界坐标；选中骨骼时改为该骨骼的世界坐标。网格间距使用资源原始单位。
左侧是资源目录，中央是原生模型视口，右侧检查器包含模型、资源与骨骼页签，
底部是动画时间轴和输出日志。目录、检查器与日志可以拖动分隔线调整大小，也可通过“视图”菜单隐藏。
F11 切换专注预览，F8 显示或隐藏整个工作台。
工作台模式恢复游戏窗口的缩放边框、最大化、还原和关闭操作。
Alt+Enter 或“视图 → 切换全屏”使用游戏原生全屏切换；F11 仍只切换专注预览布局。
拖动缩放期间保留上一帧，结束时通过原生设备重置流程同步渲染尺寸；跳过重置流程额外提交的两次空帧。
关闭按钮先释放预览资源再结束工作台。

资源目录默认聚焦资源内容：成功解码的 ECD / EXF / JKR 包装链合并显示为内部内容，并保留外层成员名称。
“视图 → 显示编码层”可恢复完整层级，查看包装元数据或导出原始编码字节；解码失败的层仍保持可见，场景资源引用不合并。
后台默认完整解析全部容器成员，
包含 MHA 命名成员及嵌套资源；完成后一次发布资源树，不以固定节点数、目录项数或深度截断。
选中节点、切换文件或更新解析结果时保留当前检查器页签；在“资源”页签单击字段可定位原始字节。
每行右侧统一预留操作区，宽度按当前字号和模型组数量计算，完整显示“模型组 N”和“预览”按钮。
预览入口只显示在模型组容器及其祖先容器；FMOD 节点保留“选择此模型”用于手动组合。
点击容器的“预览”会替换当前预览为该节点内的模型组并切到“模型”页签。
资源检查器的“加入预览”和“作为场景载入”同样只列出当前节点内的模型组。
完整动画节点右侧提供“播放”，将所选片段绑定到当前模型并从头播放；轨道与通道保留查看和展开，双击资源不触发加载。
目录随窗口高度伸缩，字段检查位于右侧“资源”页签。动画目录先完整列出各条动画，
展开某条动画时由后台线程生成其轨道和通道明细。
特效库和动作特效事件同样按需展开；稀疏索引按原始范围完整保留，不为数万个空槽生成树节点。
目录记录数与游戏外部指定的消费组数分别标示；空槽保留为空项。
模型包内的特效目录、独立材质参数组、FMOD 渲染参数及分组字数据、FSKL 第三种节点布局也可检查。
独立 MOT 按完整结构识别，保留空通道轨道；事件相机可展开视野角、位置、滚转角和目标的逐帧数组。
带 UTF-16 BOM 的文本占位按文本显示，原始字节保留。

场景资源可检查光照与后处理、渲染参数、物件实例、HITS 碰撞网格和 KEFFECT 关键帧。
旧场景环境参数、旧渲染表和区域相机按场景容器中的原生槽位识别，各自使用独立布局；
区域相机保留空间网格、区域记录与引用偏移，不与逐帧事件相机混用。
物件包按照成员描述表区分模型、骨架、贴图、控制表和动画；跨资源引用按场景目录中的资源 ID 与成员类型解析。
`kind 14` 的附加字表可展开检查头部、数量和全部 32 位值；原生加载器跳过此成员，
因此保留未确认字段的原值，不将它们命名为哈希、骨骼索引或动画参数。
`stage-hd` 中的光照补充包不包含场景几何，模型需从 `stage` 中对应编号的主场景资源查看。

资源组合允许从不同文件分别选择 FMOD 模型、FSKL 骨架和多个贴图来源，再加载预览。
选择 TXB 贴图组或单张 PNG / DDS 会替换已选贴图来源；“追加贴图”按顺序增加来源，允许同一来源重复占用不同图槽。
组合面板显示各来源占用的图槽范围并支持逐项移除。贴图组按内部顺序展开，单张图片占一个图槽；切换文件保留手动组合。
例如 `f00_body.abn` 的部分素材在包内 PNG 之外还引用游戏提供的共享肤色图槽 1，
可从 `parts/f00/f_skin.txb` 选择所需图片并追加；工具不按模型名称猜测外部图槽的选择。
`npc/n37b0000.bin` 的内置图槽 0 是 1×1 占位图，当前原生解码得到完全透明像素；游戏绘制时会将部分材质的贴图句柄
替换为 `npc/n37s0000.txb`，并设置实例颜色。预览底模时，可打开该 TXB 并点击“选择此贴图组”，
将它放入图槽 0，再从“模型”页签点击“加入预览”。相邻的 `n37b0001.bin`、`n37b0002.bin`
自带有效的 128×128 贴图，不需要同样替换。完整外观中的部件与实例颜色仍由游戏逻辑提供。
静态网格可不带骨架，带权重的模型必须使用匹配骨架。容器中相邻的模型、骨架、贴图，以及内层模型/骨架与外层贴图
都会提供组合加载入口。一个包中的多套模型分别列出，可同时显示，并各自选中、隐藏或移除；同一资源重复加入会选中现有项。骨骼可高亮、显示父子关系并双击聚焦；匹配的 MOT 可播放、暂停和定位帧，各模型保留自己的动画状态。
模型、骨架、贴图分别成列存放的包也按同一序号组合，例如 `mytra.bin` 的两套资源。
加载失败的模型在列表中保留具体错误，不再默默留下上一包的模型作为替代。
预览每帧清理颜色与深度缓冲，隐藏、移除或切换文件不会留下旧画面。
每个网格绘制后恢复原生标准混合状态，防止加色效果泄漏到后续模型或下一帧；例如 `em001`
附加模型的加色网格不会再让普通主体混入背景色。材质本身声明的透明与加色效果仍按原生方式绘制。
各模型按实际节点数维护独立的世界矩阵和蒙皮矩阵缓存，不再要求骨架总数不超过 64 或节点 ID 小于 64。
节点遍历、动画绑定及每帧采样使用迭代方式；每个网格单独映射到其绘制所需的矩阵槽位。
动画按照原生根节点和标签的实际遍历匹配，不再要求单根、所有节点同标签或轨道覆盖整副骨架；
只有唯一匹配的分组会绑定，其他分组不参与该片段。相邻同帧关键点保留原始顺序。
零条显式骨骼影响按原生逻辑使用槽位 0 的完整权重，源权重不裁剪、不归一化；
动画中叶节点的零缩放允许保留，实际生成非有限矩阵时才报告变换错误。
单次原生蒙皮绘制仍有 32 个矩阵上传槽位，另保留资源池容量、原生字段宽度和索引有效性检查。
“骨骼”页签可为任意节点显式设置姿态跟随，使用来源节点的世界矩阵与当前节点自身的逆绑定矩阵。
跟随关系仅属于当前预览模型，支持跨根骨架并拒绝循环，可单独解除或全部清除。
独立部件的装配关系由游戏实例逻辑补充，工作台不根据文件名、物种或结构指纹自动推断。
例如 `em001` 的尾巴是同一 FMOD 的网格 1、FSKL 的第二棵骨架；原生完整姿态对应
节点 45、46 跟随 43，节点 47 跟随 44。这些关系可显式设置，不改写源文件或骨架链接。
贴图由各模型独立持有原生句柄，构建材质时仅临时借用一个动态目录槽，解除原先 128 张连续贴图的限制。
贴图分配仍检查原生句柄池的实际剩余容量，释放模型时同步释放其贴图；刚体模型中的材质副本也保持正确引用。
空 TXB 可检查并参与组合，绘制需要追加有效的默认贴图；缺失图槽不会以空句柄或其他图片冒充。
材质引用表保留全部原值，预览只读取原生使用的前四项。
右侧“模型”页签可按原始编号显示、隐藏或单独查看当前模型的子网格，并恢复全部显示。
显隐只影响当前模型的绘制，原始几何、其他模型与导出数据保持完整。
某些资源包含共面但 UV 不同的网格，同时显示会发生深度冲突；例如 `weapon/wi127-so.bin`
中的网格 0/1、2/3 重叠，可分别切换检查。工作台不擅自删除或合并这些网格。
原生绘制范围与相机比例随中央视口大小更新；骨骼标记使用同帧视口投影并裁切在预览区内。
在预览区左键拖动环绕、中键或 Shift+左键拖动平移、滚轮缩放；Mac 触控板可按住 Shift 后按压拖动平移。
平移同时移动相机和环绕中心，速度随观察距离调整。
平移时结束对骨骼的跟随，并从其当前位置继续移动；按 F 聚焦全部模型或重新聚焦骨骼可恢复观察中心。
动画可用空格播放/暂停，
时间轴支持拖动定位和前后逐帧。快捷键不会截获文本输入。
输出日志保留最近 200 条状态变化，支持复制与清空；这里只记录工作台操作反馈，不收集游戏日志。

场景默认为空。将资源组合“作为场景载入”才创建场景资源；“启用场景”控制显示，
“卸载场景”释放资源。这里复用原生模型绘制，并未启动游戏任务或地图中的逻辑对象。

资源扫描、读取、解析和导出由后台线程处理。快速选择文件会替换待处理的选择，旧结果
不会覆盖新选择；读取和解码按实际文件范围、声明大小及可分配内存检查，不设置固定容量阈值。导出保留所选节点的原始字节，
写入 `export_root` 中的新文件，不覆盖原游戏资源或已有导出。
导出整份原文件时保留文件名和后缀；容器中的完整 PNG、DDS、Ogg、FMOD、FSKL、MOT、
TXB、MOMO、MHA 资源使用对应类型后缀。骨骼、轨道、mip 等内部片段，以及后缀未确认的数据，
使用 `.bin`，名称包含类型、数据层编号和偏移。导出名称保留中文，移除路径和 Windows 不允许的字符；
首次使用原名称，同名文件追加编号。此操作只提取字节，不执行模型、动画或图像格式转换。

[`mhf-resource`](../../shared/resource/README.md) 提供可在非 Windows 主机测试的文件格式类型。
字段保留原始编码、索引、偏移、位标记、未知值和顺序；原生指针仅出现在工作台的
Windows 后端。文件格式不猜测未知单位、插值模式或不存在的格式版本。

原生预览针对已核对的 ZZ HD 客户端接口，在调用无边界检查的游戏代码前验证资源布局、
索引、矩阵、动态资源池容量和函数签名。文件能够被检查不代表其全部变体都已支持原生绘制；
不支持的布局会保留检查和导出能力，并给出具体原因。PNG/DDS 当前提供结构检查，
没有独立图像画布；完整地图专用数据及效果运行逻辑尚未接入。

可在宿主机使用相同解析器审计目录，无需启动游戏：

```sh
cargo run --manifest-path mhf/Cargo.toml -p mhf-workbench --example inspect --target aarch64-apple-darwin -- --tree /path/to/dat/emmodel/em019.pac
```
